Run it yourself

Paste it into PowerShell from the project folder.

Match: the share of a gene's 21-letter DNA pieces found in your sequence. At 80% or more, the gene counts as present.

Thread: one worker. More threads split the genomes between them so the job finishes sooner.

The genes: blaTEM resists penicillin-type antibiotics, tetA resists tetracyclines, sul1 resists sulfonamides.

Sequential vs parallel

Both versions do the same job: check every genome for the three resistance genes.

Sequential

One core checks the genomes one after another.

24.9 ms
for 1,000 genomes

Parallel (OpenMP)

Many threads each check a share of the genomes at the same time.

4.7 ms
for 1,000 genomes with 16 threads, 5.3× faster
Same answers either way. Both versions classified all 1,000 genomes correctly (250 each with blaTEM, tetA, sul1, and no gene). The two result files, predictions_seq.csv and predictions_omp.csv, are identical.

What the program needs

Genomes (-i): a CSV with one bacterial genome per row and the columns sample_id, species, animal_source, amr_status, amr_gene, sequence, k.

Reference genes (-r): a FASTA file listing the resistance genes to look for. Default: data/reference_genes.fasta.
